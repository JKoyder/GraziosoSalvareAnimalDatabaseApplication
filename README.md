To run this application you will need to use Node Package Manager (NPM) to begin hosting the REST API and single page application. Open two command prompt windows and change their directory to the 'grazioso_salvare' and 'grazioso_salvare_api' folders. Make sure to seed the database within the API folder using the "node .\models\seed" command (This will take a moment). Then, within each command prompt instance, run "npm start". Only when they are both running will the SPA website work appropriately. Please check out my breakdown the application here: https://www.youtube.com/watch?v=xHiN0-kakCA

This project is an enhancement of a Computer Science program artifact. The application was originally designed in Python using the Dash Framework. This enhancement has transferred the architecture over to the MEAN stack, where a backend REST API is used to fetch data from a database that is then returned to a frontend single page application. In its current state, the application consists of a data table, filters, an animal by count graph, and an animal by count over time graph. When a user opens the single page application, data is fetched from the app API through an Express controller. The returned data is used to populate the Angular table and graphs. The data table incorporates sorting and pagination features so that users can easily traverse this data. The table filters can be used to filter the data by search and rescue/animal type. This similarly fetches data from the app API and updates the table and graphs. The data for this application is stored on a Mongo database which communicates with the app API through MongooseODM.
